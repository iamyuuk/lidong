# 立冬 · 和你一起走到冬天

一个纯静态、手机优先的立冬小页面。没有构建步骤，没有外部字体和图片，三个文件上传到任意静态托管就能用。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构、所有文案、信的内容 |
| `styles.css` | 全部样式 |
| `app.js` | 雪花、逐字点亮、雪地写字、拆信、淋雪 |

直接双击 `index.html` 就能在电脑上看；手机上需要先部署，或者用同一局域网里的静态服务器打开。

## 部署

把 `index.html`、`styles.css`、`app.js` 放在同一个目录，上传即可：

- **GitHub Pages**：推到仓库根目录 → Settings → Pages → Deploy from a branch
- **Netlify / Vercel / Cloudflare Pages**：把整个文件夹拖进去
- **自己的服务器**：放进任意网站目录

建议在 **2026 年 11 月 7 日（立冬）当天** 发布，首屏写的是「今日立冬」。

## 想改的地方

文案全部在 `index.html`：

- 首屏日期、时间、`今日立冬 / 宜拥抱`：`.hero-meta`、`.today-badge`
- 序：`#litText`、`.aside`、`.almanac-line`
- 四季：`.season-list` 里的四行
- 信：`index.html` 最下面的 `<div id="letterSource" hidden>` 里是正文，落款在同段的 `.paper-sign`；信封上的字在 `.env-to` / `.env-small`
- 终章：`.poem`、`.msg-big`、`.msg-small`、`.site-foot`

颜色在 `styles.css` 顶部的 `:root` 里改。

## 交互

- **轻触屏幕**：从指尖爆开一小簇雪，并荡开一圈涟漪
- **滑动**：雪会顺着手指的方向偏
- **雪地写字**：手指划开雪面，写下的字会一直留在雪上；想重来，点右下角的「抹平雪面」
- **拆信**：轻触信封，纸展开，信一个字一个字出现；点信纸可以立刻显示全文
- **一起淋雪**：雪变大，结尾的话出现
- **分享这场雪**：手机支持时调用系统分享，不支持时复制链接

## 小提醒

- 分享和剪贴板在 HTTPS 下最稳；用 `file://` 直接打开时，复制链接可能被浏览器拦下。
- 页面使用系统字体（宋体 / 苹方），不依赖网络；断网也能完整显示。
- 动效会尊重系统的「减少动态效果」设置。
